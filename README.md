# AmazingBot — шахта и рыбалка для Amazing Online

Windows-приложение для повторения записанных рабочих циклов в профессиях:
- шахта;
- рыбалка удочкой;
- рыбалка сетью.

В приложении нет режима теплицы/грядок. Выберите профессию на вкладке **«Настройки»**, запишите цикл на вкладке **«Маршруты»** и запустите бота. Маршрут повторяется до кнопки **«Стоп»** или F12.

## Как пользоваться

1. Скопируйте `configs/config.example.json` в `config.json` рядом с приложением.
2. Запустите Amazing Online в оконном/безрамочном режиме и откройте AmazingBot.App.
3. Во вкладке **«Маршруты»** выберите `mine_cycle`, `fishing_rod_cycle` или `fishing_net_cycle`, нажмите «Начать запись», выполните один полный цикл и нажмите F10. Для стабильного повтора закончите в исходной точке.
4. Во вкладке **«Настройки»** выберите ту же профессию и сохраните. Имя маршрута заполняется автоматически, его можно изменить.
5. Запустите бота. Сначала проверьте один цикл; F12 или «Стоп» немедленно остановит повтор.

Это макро-повтор записанных клавиш, кликов и пауз, а не распознавание результата добычи или случайной поклёвки. Для рыбалки проверьте тайминги маршрута. Кнопка **«Подсветка руды»** запускает экранный поиск по шаблону `templates/ore.bmp` и рисует рамки вокруг похожих участков. Он видит только то, что уже захвачено на экране: чтение памяти игры и обнаружение руды сквозь стены не реализованы. Для выхода из оверлея нажмите F11.

## Сборка

```powershell
dotnet build AmazingBot.sln -c Release
dotnet run --project src/AmazingBot.App -c Release
```

Windows 10/11, .NET 8 SDK для сборки. Приложение должно иметь те же права, что и игра. Для аварийной остановки нажмите F12.
