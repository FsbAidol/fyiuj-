# AmazingBot — бот для Amazing Online (грядки)

Windows-бот для Amazing Online (клиент Windows), автоматизирующий игру на грядках.
Написан на C# / .NET 8, **без внешних зависимостей** — распознавание по шаблонам
(нормализованная кросс-корреляция) и ввод сделаны на чистом Win32 P/Invoke.

**Скачать готовую Windows-сборку:** [GitHub Releases](https://github.com/FsbAidol/fyiuj-/releases/latest) — GUI (`AmazingBot.App.exe`), консоль (`AmazingBot.exe`) и пример конфигурации.

В GUI есть мастер «Простая настройка»: он позволяет снять образцы значков прямо с экрана игры и сопоставить вредителей с химикатами и слотами хотбара. Бот визуально проверяет каждую указанную грядку, ищет состояния растения, вредителей, потребность в удобрении и воде, затем выполняет настроенное действие. Для неизвестных элементов сначала требуется один раз снять образцы; бот не распознаёт произвольные значки без обучения.

Полная инструкция по установке и использованию: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md) (также входит в архив материалов релиза как `INSTRUCTION.md`).

> Внимание: использование бота может нарушать правила игры, ваш аккаунт может быть заблокирован.
> Используйте на свой страх и риск. Бот предназначен для автоматизации рутины на **своём** аккаунте.

## Что умеет (по ТЗ)

### 1. Грядки
- Посадка растений из инвентаря (настраиваемая клавиша семян, счётчик семян)
- Лечение паразитов **нужным** химикатом (таблица «паразит → химикат → клавиша хотбара» в конфиге)
- Удобрение почвы (по распознаваемой потребности)
- **Полив с точным расчётом литров**: бот знает вместимость лейки, расход за нажатие и сколько
  литров уже вылито в каждую грядку; добирает ровно недостающее (`буквально ceil((нужно − вылито) / литров_за_клик)` нажатий)
- Сбор урожая **или** клонирование — переключается `harvestMode: "harvest" | "clone"` (и в меню)

### 2. Пополнение лейки
- Из фляги с водой в инвентаре (`flaskLiters` за флягу, списывается со счётчика)
- Из бочки **по записанному маршруту** (`watering.mainBarrelRoute`), с **резервной бочкой**
  (`watering.backupBarrelRoute`), если в основной закончилась вода
  (определит по шаблону «бочка пуста», если он задан, либо когда основная не дала воду)

### 3. Пополнение через багажник машины
- Когда заканчиваются фляги / химикаты / удобрения / семена — бот едет к машине
  по маршруту `trunk.route`, открывает багажник (`openKey`) и забирает `trunk.items[]`
- Сломанная лейка автоматически меняется на целую из багажника
- При респавне транспорта бот замечает уведомление (`car.respawnNoticeTemplate`),
  идёт по `car.claimRoute` и занимает машину (`claimKey`, по умолчанию `F`), чтобы она не пропала

### 4. Прочее
- Настраиваемый интервал проверки грядок (`checkIntervalSeconds` или меню, пункт 7)
- Анти-афк: периодически нажимает клавиши и слегка двигает мышь (`antiAfk`)
- **Авто-отключение**: когда ВСЕ грядки за проход собраны/клонированы — бот сам останавливается
  (`autoDisableOnAllBedsDone`, по умолчанию включено)
- Экстренная остановка **F12** в любой момент
- Подробные логи (консоль + `logs/amazingbot-YYYYMMDD.log`)

## Требования

- Windows 10/11, игра **в оконном** или безрамочном режиме (не эксклюзивный полноэкранный)
- [.NET 8 SDK](https://dotnet.microsoft.com/download) для сборки (достаточно один раз)
- Масштаб Windows 100% или запуск бота с правами, не ниже прав игры (иначе BitBlt/SendInput не сработают)

## Сборка и запуск

```powershell
cd AmazingBot
dotnet build -c Release

# Оконное меню (рекомендуется):
dotnet run --project src/AmazingBot.App -c Release
# Консольное меню:
dotnet run --project src/AmazingBot -c Release

# Один exe без консоли (можно переносить на машину без .NET):
dotnet publish src\AmazingBot.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Готовый `AmazingBot.App.exe` положите рядом с `config.json`, папками `templates/`, `routes/`.
По умолчанию бот ищет `./config.json` в текущей папке, затем `configs/config.example.json`.
`configs/config.example.json` — готовый стартовый файл (JSON с комментариями, они поддерживаются).

**Пошаговая установка и первичная настройка — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).**

## Быстрый старт

1. `copy configs\config.example.json config.json`
2. Откройте `config.json`: впишите `windowTitleContains` (кусок заголовка окна игры),
   горячие клавиши под свою раскладку хотбара, вместимость лейки и литры.
3. Запустите игру и AmazingBot.App.exe. Во вкладке **«Простая настройка»** снимите образцы состояний растения и кнопок, обводя их на игровом снимке. В таблице добавьте вредителей, нужные химикаты и клавиши хотбара.
4. Для дополнительных предметов интерфейса (фляги, предметы багажника, уведомления) при необходимости используйте вкладку «Шаблоны» и руководство `templates/README.md`.
5. Нажмите **«Проверить образцы»** и убедитесь, что они видны в игре.
6. Во вкладке **«Грядки»** нажмите «Найти грядки автоматически…», обведите середину одной грядки на снимке, проверьте рамки и подтвердите. Координаты бот заполнит сам; F8/F9 остаются запасным ручным способом.
7. Пункт **3** — запишите маршруты (полный круг «от грядок к цели и обратно»):
   - `barrel_main` — к основной бочке,
   - `barrel_backup` — к резервной бочке (если есть),
   - `to_car` — к машине/багажнику.
   Пропишите имена маршрутов в `watering.mainBarrelRoute` / `watering.backupBarrelRoute` /
   `trunk.route` / `car.claimRoute` (по умолчанию уже `barrel_main`, `barrel_backup`, `to_car`).
8. Заполните стартовый инвентарь в `inventory` (flasks/fertilizer/seeds/chemicals) —
   бот ведёт внутренний счёт и сходит в багажник, когда что-то закончится.
9. **Пункт 2** — пробный один проход, посмотрите логи. Если всё хорошо — **пункт 1**.

## Как устроен цикл бота

```
повтор каждые checkIntervalSeconds:
  ├─ респавн транспорта? → маршрут claimRoute + F/посадка
  ├─ чего-то закончилось (фляги/хим./удоб./семена) или лейка сломана? → багажник
  └─ проход по грядкам:
       для каждой грядки: открыть панель →
         готова? → Собрать/Клонировать (harvestMode) → дальше
         иначе: паразит? → нужный химикат
                нужно удобрение? → удобрение
                низкая влажность? → полить ровно до litersPerBed (точный расчёт)
                пусто? → посадить семя
       все грядки собраны/клонированы и autoDisableOnAllBedsDone? → СТОП
между проходами: анти-афк (раз в antiAfk.intervalSeconds), F12 — выход
```

## Командная строка

```
AmazingBot                    — интерактивное меню
AmazingBot --once             — один проход и выход
AmazingBot --screenshot       — снять скриншот окна в screenshot.bmp
AmazingBot --check-templates  — что распозналось на экране прямо сейчас
AmazingBot --record-route X   — записать маршрут X (F10 — конец)
AmazingBot --calibrate-beds   — калибровка грядок (F8/F9)
AmazingBot --config PATH      — другой конфиг
```

## Честные ограничения

- Шаблоны — ручные. Игра обновится/поменяет иконки → переснимите шаблоны.
- Количество предметов бот **не умеет считывать с экрана** (нет OCR): он стартует с чисел из
  `inventory` и вычитает по мере использования; если пополнили инвентарь в игре вручную —
  поправьте числа в конфиге перед запуском.
- Счётчик воды в лейке — тоже внутренний (сколько вылито из вместимости); если в игре
  лейка наполняется не до 100% (остаток от фляги меньше вместимости и т.п.), считайте
  приближение: вылито по факту всегда ≤ вылитого ботом.
- Резервная бочка переключается, когда либо задан пустой шаблон основной (`mainBarrelEmptyTemplate`),
  либо основная бочка не пополнила лейку — в этом случае бот идёт к резерву;
  и если и она пуста — полив останавливается до следующего пополнения (бот сообщит в лог).
- Эксклюзивный полноэкранный режим не захватывается; используйте оконный/безрамочный.
- Клики и клавиши отправляются через SendInput: игра и бот должны быть одного уровня целостности
  (оба не от админа, либо бот тоже от админа).

## Структура проекта

```
AmazingBot.sln
ИНСТРУКЦИЯ.md              — пошаговая установка и использование
src/
  AmazingBot.App/             — оконное меню (WinForms): Главная / Грядки / Маршруты / Шаблоны / Настройки
    Program.cs, MainForm.cs
  AmazingBot/                 — ядро + консольное меню (та же логика)
    Program.cs                  — точка входа, CLI
    ...
  Core/   Bot.cs              — главный цикл (проходы, авто-отключение, F12)
          Logger.cs           — лог в консоль+файл
  Native/ NativeMethods.cs    — все P/Invoke (user32/gdi32)
          NativeStructs.cs    — структуры Win32
  Vision/ ScreenCapture.cs    — захват окна игры через BitBlt
          BitmapImage.cs      — буфер BGRA
          BmpCodec.cs         — чтение/запись BMP (шаблоны) без внешних библиотек
          TemplateMatcher.cs  — NCC-поиск шаблона (2 прохода + NMS)
          VisionService.cs    — кэш шаблонов, Find/Exists/WaitFor
  Input/  Mouse.cs, Keyboard.cs — SendInput
          Route.cs            — модель маршрута, проигрыватель, рекордер (низкоуровневые хуки)
  Config/ BotConfig.cs, ConfigService.cs — модель config.json, загрузка/валидация/сохранение
  Game/   BotContext.cs, GameClient.cs   — контекст и низкоуровневые игровые операции
  Tasks/  GardenTask.cs       — грядки: паразиты/удобрение/полив/посадка/сбор
          WateringTask.cs     — точный расчёт литров, фляга/бочки/резерв
          TrunkTask.cs        — багажник: пополнение и замена сломанной лейки
          CarClaimTask.cs     — занятие машины при респавне транспорта
          AntiAfkTask.cs      — анти-афк
  Ui/     ConsoleMenu.cs      — консольное меню: запуск, запись маршрутов, калибровка, настройки
configs/config.example.json   — пример конфига с комментариями
templates/README.md           — как нарезать шаблоны
routes/                       — записанные маршруты (создаётся при записи)
```
