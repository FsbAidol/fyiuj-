# Экранная подсветка руды

На вкладке «Главная» нажмите **«Подсветка руды»**. При первом запуске выберите BMP-файл с небольшим уникальным фрагментом руды, снятым в игре. Программа скопирует его как `templates/ore.bmp` и будет искать похожие области в кадре игры. Совпадения обводятся поверх окна. Порог совпадения сейчас фиксирован на 0.82; похожие текстуры могут давать ложные срабатывания.

Оверлей обновляет кадр примерно раз в 0.7 секунды. Нажмите **F11**, чтобы закрыть его. Игра должна быть в оконном или безрамочном режиме.

Это экранный поиск шаблона, а не ESP через стены: невидимые/закрытые геометрией руды он обнаружить не может. Программа не читает память игры и не получает координаты игровых объектов. Для качества используйте чистый, хорошо различимый фрагмент; BMP должен быть небольшим и без лишнего фона.
