# Шаблоны для распознавания (BMP)

Бот находит элементы интерфейса по картинке. Шаблоны — это **32-битные BMP**-файлы
(именно BMP, не PNG — так бот читает их без внешних библиотек).

## Как нарезать шаблоны

1. Запустите Amazing Online в **оконном** режиме.
2. Запустите бота → пункт **5) «Сохранить скриншот окна игры»** (или `AmazingBot --screenshot`).
   Появится `screenshot.bmp` — точный снимок клиентской области окна.
3. Откройте `screenshot.bmp` в Paint / любом редакторе и **вырежьте** маленькие фрагменты:
   иконку паразита, кнопку «Собрать», полоску влаги и т.п.
4. Сохраните каждый фрагмент отдельным файлом **как BMP (32 бит, без сжатия)**
   в эту папку (`templates/`). Имя файла = имя шаблона (см. ниже), расширение `.bmp`.
5. Проверьте себя ботом: пункт **6) «Проверить шаблоны на экране»** — он покажет,
   что распознал и с каким счётом (score ≥ ~0.8 — хорошо; меньше 0.6 — переснимите шаблон,
   возьмите больше кадрирования или уникальнее контрастный фрагмент).

Советы:
- Берите **только уникальные** фрагменты (значок, а не фон вокруг него).
- 20×20…80×80 пикселей обычно достаточно; не берите весь экран.
- Переключайте интерфейс в игре в один и тот же масштаб/качество.
- Если игра меняет языковую версию — переименуйте фрагменты с текстом или переснимите.

## Обязательные шаблоны

| Файл | Что это |
|---|---|
| `crop_ready.bmp` | Индикатор/иконка «растение готово к сбору» в панели грядки |
| `bed_empty.bmp` | Признак пустой грядки в панели («Пусто» / пустая иконка семени) |
| `needs_fertilizer.bmp` | Значок «нужно удобрение» |
| `moisture_low.bmp` | Индикатор низкой влажности (полоска воды почти пуста) |
| `moisture_full.bmp` | Индикатор полной влажности (необязателен, но ускоряет досрочное прекращение полива) |
| `btn_harvest.bmp` | Кнопка «Собрать» |
| `btn_clone.bmp` | Кнопка «Клонировать» |
| `can.bmp` | Иконка целой лейки (в хотбаре / в багажнике) |
| `can_broken.bmp` | Иконка сломанной лейки |

## Зависят от ваших настроек

| Файл | Когда нужен |
|---|---|
| `<имя closePanel>.bmp` | Если `templates.closePanel` не пуст — крестик закрытия панели |
| `<parasite>.bmp` | Для каждого `parasites[].parasite` — иконка паразита |
| `<chemical>.bmp` | Для каждого `parasites[].chemical` — иконка химиката |
| `seed_*.bmp` / иконка семени | Для предметов багажника `trunk.items[].template` (семена и т.п.) |
| `fertilizer.bmp` | Для `trunk.items[]` с удобрением |
| `flask.bmp` | Для `trunk.items[]` с флягой |
| `barrel_empty.bmp` | Только если задан `watering.mainBarrelEmptyTemplate` / `backupBarrelEmptyTemplate` |
| `transport_respawn.bmp` | Если включена проверка респавна транспорта (`car.respawnNoticeTemplate`) |

Имена файлов произвольные — главное, чтобы они совпадали со значениями в `config.json`.
