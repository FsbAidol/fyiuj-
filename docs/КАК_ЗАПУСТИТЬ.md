# Как запустить (кратко, по-русски)

## 0. Что нужно
* Python 3.10+
* игра Amazing Online в эмуляторе (LDPlayer/BlueStacks/MuMu) или на телефоне
* (по желанию) Tesseract OCR — для распознавания буквы при очистке сетки
* (по желанию) adb — platform-tools, если игра в эмуляторе/на телефоне

## 0.5 Самый простой путь — готовый exe
1. Скачайте `AmazingBot-onefile-win64.zip` с
   https://github.com/FsbAidol/fyiuj-/releases/tag/latest
2. Распакуйте **всю папку** (не запускайте из архива).
3. Запустите `AmazingBot.exe` → меню → пункт 4 («Прогон на симуляторе»),
   затем пункт 2 («Проверка»), затем пункт 1 («Запустить бота»).

Если Windows SmartScreen/антивирус ругается — «Подробнее» → «Выполнить в любом
случае» или добавьте папку в исключения (сборка без цифровой подписи).
`config.yaml`, `templates\`, `scripts\` лежат рядом с exe — их можно править.

## 1. Установка из исходников (один раз)
```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt
```

## 2. Подключение игры (эмулятор)
```bash
adb devices
```
В списке должно быть устройство. Если пусто — включите отладку по USB в
настройках эмулятора.

## 3. Проверка
```bash
python -m bot check
python -m bot snapshot -o samples/shot.png
```
`samples/shot.png` — скриншот, который видит бот. Убедитесь, что на нём
открыт нужный экран игры.

## 4. Шаблоны (один раз, ~10 минут)
В репозитории лежат демо-шаблоны (`demo_templates/`) — они от симулятора.
Для настоящей игры:
```bash
python -m bot snapshot -o samples/shot.png
python -m bot.tools.crop_template samples/shot.png 900,600,1100,700 templates/cast_button.png
```
Обязательный минимум: `cast_button` и `bite`. Дальше по мере надобности:
`collect`, `bag_button`, `close_button`, `food_item`, `water_item`,
`net_item`, `trunk_window`, `trunk_button`, `net_broken`, `trash_on_net`.

В `config.yaml`:
```yaml
vision:
  templates_dir: templates
```

## 5. Пробный прогон без игры
```bash
python -m bot demo --kg 500 --fish-kg 5 --speed 120 --break-every 9
```
Это покажет весь цикл на симуляторе: ловля, мусор, QTE-буква, разрыв сетки и
поездка в багажник, автостоп на 500 кг.

## 6. Боевой запуск
```bash
python -m bot run            # или --dry-run, чтобы только смотреть
```
Хоткеи: `F8` — пауза/продолжить, `F9` — сброс счётчика кг, `F12` — стоп.
Логи: `logs/bot.log`. Скриншоты ошибок: `debug/`.

## 7. Где что менять
| Хочу | Файл |
|---|---|
| лимит 500 кг, запас, зависание | `config.yaml` → `safety`, `weight` |
| когда есть/пить | `config.yaml` → `hud.*.low` |
| что нажимать, чтобы поесть | `scripts/eat.yaml`, `scripts/drink.yaml` |
| как дойти до машины и взять сетку | `scripts/trunk_restock.yaml` |
| как чистить сетку | `scripts/clear_trash.yaml` |
| частота анти-АФК | `config.yaml` → `anti_afk` |
| зона поиска буквы QTE | `config.yaml` → `qte.region` |

## Частые проблемы
| Симптом | Причина | Что делать |
|---|---|---|
| «template ... not found» | нет шаблона | снять шаблон, проверить `templates_dir` |
| Бот не жмёт кнопку | шаблон найден неверно (фон) | переснять шаблон без фона |
| «no bite within 60s» | неверный шаблон поклёвки или зона | обновить `fishing.bite.template`, регион `[0,0,1,1]` |
| Сетка «чинится» бесконечно | не снимается индикатор `net_broken` | снять шаблон индикатора |
| Буква QTE не распознаётся | нет Tesseract | поставить Tesseract или жить на геометрии |
| Бот падает на «adb not found» | нет platform-tools | установить adb или `device.backend: desktop` |
